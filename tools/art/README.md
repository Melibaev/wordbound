# Арт для WORDBOUND: цветной вебтун

Приложение само подхватывает картинки `art/<эпизод>/<NN>.jpg` (NN = номер панели, две цифры: `01`, `02`...). Если картинки нет, остаётся SVG-заглушка. Для нескольких ключевых панелей можно добавить `art/<эпизод>/<NN>.mp4` (короткая зацикленная анимация). Список имеющихся файлов лежит в `art/manifest.json`, его пересоздают скрипты (руками править не нужно).

Нужен Python 3.12 и Pillow только для арт-инструментов (на приложение это не влияет):

```
python -m pip install --user pillow
```

Правила размера: каждая картинка до 250 КБ (скрипты сжимают сами: ширина 1080 px, JPEG ~82, метаданные удаляются). Видео только для нескольких ключевых панелей, каждое до 4 МБ.

Стиль везде один: цветной вебтун (Korean webtoon, full colour), формат кадра 4:5, без текста на картинке, сверху свободное место под реплики. Названия реальных манхв/студий/художников в промптах не используются.

## Маршрут A. Вручную (бесплатно, подписка Google AI Pro)

1. Сгенерируй промпты:
   ```
   python tools/art/prompts.py
   ```
   Появятся `art-prompts/characters.md` и `art-prompts/<эпизод>.md`. Описания персонажей и локаций берутся из `story/bible.md` (визуальная библия), а если её нет, из `data/story.json`. Поле `art` у панели (описание кадра) используется, если оно есть.
2. **Персонажи.** В Gemini (создание изображений) или на flow.google.com вставь промпт персонажа из `characters.md`, выбери удачный результат, скачай. Сохрани его как `art/refs/<id>.jpg`:
   ```
   python tools/art/import_art.py <папка_с_загрузкой> --refs dan
   ```
   (в папке берётся самая новая картинка; для `--refs` аргумент эпизода не нужен).
3. **Панели.** В `art-prompts/<эпизод>.md` у каждой панели указано: имя файла, какие референсы персонажей прикрепить, готовый английский промпт. Для единообразия лиц всегда прикладывай референсы. Скачивай результаты в одну папку.
4. **Импорт:**
   ```
   python tools/art/import_art.py "C:\Users\...\Downloads\s1e01" s1e01 --dry-run
   python tools/art/import_art.py "C:\Users\...\Downloads\s1e01" s1e01
   ```
   Порядок файлов: если в имени КАЖДОГО файла ровно одно короткое число (`panel 7.png`), идут по числу; иначе по времени изменения, от старого к новому (то есть в порядке скачивания). Принудительно: `--order mtime|number|name`. Файлы по порядку ложатся на панели 01, 02, ... ; чтобы начать с другой: `--start 05`. `--dry-run` показывает соответствие, ничего не записывая.
5. **Видео (по желанию, только для ключевых панелей).** В `<эпизод>.md` у первой, последней и «action»-панелей есть промпт для Veo во Flow (image-to-video из картинки панели, 4 to 8 с). Скачай ролик и положи:
   ```
   python tools/art/import_art.py - s1e01 --video 17 "C:\...\clip.mp4"
   ```
   Больше 4 МБ скрипт предупредит: обрежь или сожми ролик.
6. Проверка: `python tools/validate_content.py`, затем открой приложение.

## Маршрут B. Через API Gemini (платно, из бесплатного кредита Google Cloud)

Официальный Gemini API, без сторонних сервисов. Скрипт: `tools/art/generate.py`. Видео через API **не реализовано** (слишком дорого для кредита): видео только вручную через Flow.

### Настройка (эти шаги делаешь сам: биллинг и ключи на моей стороне не трогаются)
1. Активируй бонусы Google Developer Program, которые идут с подпиской AI Pro: https://developers.google.com/profile
2. В Google AI Studio (https://aistudio.google.com) создай API-ключ, привязанный к проекту Google Cloud, на котором есть этот кредит (у моделей для картинок нет бесплатного уровня: нужен включённый биллинг).
3. В Google Cloud Console, раздел Billing, задай **бюджет и оповещение** (Budgets & alerts), например на сумму кредита.
4. Положи ключ в переменную окружения (Windows, потом открой НОВЫЙ терминал):
   ```
   setx GEMINI_API_KEY "ВАШ_КЛЮЧ"
   ```
   Ключ никогда не передаётся аргументами, не печатается и не пишется в логи.

### Команды
```
python tools/art/generate.py --characters --dry-run         # листы персонажей: сколько и за сколько
python tools/art/generate.py --characters --max 6
python tools/art/generate.py --episode s1e01 --dry-run       # промпты и смета, ничего не отправляется
python tools/art/generate.py --episode s1e01 --panels 1-4 --max 4
python tools/art/generate.py --episode s1e01 --panels 2 --force --model gemini-3-pro-image
```
Флаги: `--panels 1,3,5-8`, `--force` (перезаписать; по умолчанию существующие файлы пропускаются), `--max N` (жёсткий лимит картинок за запуск, по умолчанию 10), `--model`.

Референсы `art/refs/<id>.jpg` автоматически прикладываются к каждой панели, где персонаж в кадре. Сначала сделай и утверди листы персонажей, потом панели.

### Модели и цена (проверено 2026-11-15, цены за картинку 1K, платный уровень)
| Модель | $ за картинку | Заметка |
|---|---|---|
| `gemini-nano-banana-2.1` (по умолчанию) | 0.0336 | дёшево, до 14 референсов |
| `gemini-3.1-flash-lite-image` | 0.0336 | плохо работает с несколькими референсами |
| `gemini-3.1-flash-image` | 0.067 | средний вариант |
| `gemini-3-pro-image` (Pro) | 0.134 | лучшее качество/консистентность, 4K: 0.24 |
| `gemini-2.5-flash-image` | 0.039 | устаревает, отключение 2027-03-15 |

Актуальные цены: https://ai.google.dev/gemini-api/docs/pricing (таблица в начале `common.py` нужно обновлять руками). `--dry-run` печатает смету перед запуском. Один эпизод (16 панелей) на модели по умолчанию примерно 0.54 доллара.

Ошибки: 429 и 5xx скрипт повторяет с паузами; на 400 и 403 печатает подсказку (чаще всего не включён биллинг, ключ от другого проекта или не включён Generative Language API).

После генерации открой картинки и проверь: лица совпадают с референсом, нет текста и пузырей. Плохие перегенерируй через `--panels N --force`.
